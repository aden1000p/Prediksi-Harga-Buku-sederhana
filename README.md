# 📚 Prediksi Harga Buku — Sederhana

[![Python](https://img.shields.io/badge/python-3.8%2B-blue)](https://www.python.org/) 
[![License](https://img.shields.io/badge/license-UNSPECIFIED-lightgrey)](LICENSE)

Prediksi Harga Buku adalah proyek pembelajaran kecil yang menggunakan regresi linier untuk memperkirakan harga buku/notes berdasarkan ukuran (diameter/ukuran fisik) dan jumlah lembar. Aplikasi ini berbentuk skrip konsol sederhana yang menerima input pengguna dan menampilkan prediksi harga.

---

## Fitur utama
- Prediksi harga berbasis Linear Regression (scikit-learn).
- Input interaktif lewat terminal: judul buku, kategori, tanggal terbit, ukuran, dan jumlah lembar.
- Menampilkan daftar buku dan prediksi harga dalam format tabel sederhana.
- Notebook (latihan.ipynb) untuk eksplorasi data dan visualisasi.
